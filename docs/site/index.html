01 · 核心能力

七个能力，一个位置

市面上的迁移工具是一次性搬运工；Context Vault 是资产库——存储、谱系、账本、审计。

快照资产库

Codex / Claude Code / DeepSeek Harness / ZCode / Antigravity 与 18 种桥接 harness 的会话，导出为供应商中立 context-snapshot 格式：内容寻址、不可变、幂等，自动 lineage 会话树与按天保留裁剪。

深度检索内核

代码感知分词（camelCase / snake_case / 路径 / 错误码 复合+子词双索引）× 块角色加权 BM25 × 有界分化时间衰减（0.65/标识符 0.80 + no_decay 开关，Recall@1 达 0.93）× Lineage 折叠。SQLite 紧凑倒排让千级快照索引体积降 87%，检索 P95 39ms。

整端批量 + 双向会话与 Skill 迁移

支持Codex ⇄ Claude Code、Antigravity .db、DeepSeek Harness V4 .jsonl.zstd 与 ZCode 的单条及整端全量批量迁移（按源 Harness/项目/关键词盘点、自动跳过同源与已迁会话、单条容错与单次主库备份），以及跨端 Skill 技能工作台（unified diff 预览、安全移除及自动备份一键回滚）；默认 dry-run，支持五槽位 Markdown 简报。

多端账本与配额

免代理只读直采 Claude Code / Codex / DeepSeek Harness / ZCode / Antigravity（含 DeepSeek V4/Flash 费率与本机 IDE 实时额度），提供 5h 滚动窗口与冷却倒计时（ETA）、多维排行与真实缓存命中率。

双时态记忆与规则编译

决策、偏好、踩坑、架构红线自动提取，每条带 快照#块 与真实时间出处；旧方案推翻自动 superseded（入侵率 0.0）。cv memory compile-rules 可按预算编译为受哨兵保护的 AGENTS.md / CLAUDE.md / .cursorrules。

双向 MCP 与 AML 记忆后端

vault_remember、vault_memorize、vault_handoff 等 8 个 MCP 工具支持 project/agent/since 作用域过滤与 budget_tokens 裁剪；按需接入多端、精确识别残留与 .bak-cv 备份安全移除；另内置 AML 多租户适配。

本地控制台与语义增强

cv serve --open 并发 SWR 首屏 <100ms 秒开：Ctrl+K 命令面板、空库 3 步引导、记忆置顶、Markdown 简报一键复制、设置与运维工作台（MCP 按需接入与移除 / Ollama 语义重排 / 备份裁剪）。

命令行安装（Windows / Linux / macOS，纯 Python 3.9+ 标准库零依赖）

$ git clone https://github.com/nghqqa/context-vault && cd context-vault && pip install -e .
$ cv setup --mcp     # 一步到位：建库 → 同步全端会话 → 账本 → 提取记忆 → 接入 MCP
$ cv serve --open    # 启动本地热索引服务并自动打开 Web 控制台 (127.0.0.1:8791)

试一次跨工具迁移（默认 dry-run，不加 --apply 绝不碰真实会话目录）

$ cv migrate ~/.claude/transcripts/ses_xxx.jsonl --target codex  # 产物先落 vault/outbox/
$ cv import --agent claude --target codex                        # 整端全量批量盘点与预演（去重/容错）
$ cv import cv_xxxx --target dsh --apply                         # --apply 写入 DSH V4 压缩会话并登记工作区
