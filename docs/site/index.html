六个能力，一个位置

市面上的迁移工具都是一次性搬运工；Context Vault 是资产库——存储、谱系、账本、审计。

快照资产库

Codex / Claude Code / 19 种桥接 harness 的会话，导出为供应商中立格式：内容寻址、不可变、幂等、自动 lineage 会话树。

诚实迁移

Codex ⇄ Claude Code 双向（双端真机验证），默认 dry-run，逐字段告诉你什么保住了、什么搬不走。另有 Markdown 交接简报档，任何 agent 都能吃。

token 账本

按模型成本、缓存命中率、5 小时窗口视图——全部从会话文件内嵌的 usage 记录聚合，不需要任何代理。

跨会话记忆

决策、偏好、摘要从历史自动提取，每条记忆注明来源快照、可回读核实。引擎接口可插拔。

MCP 记忆后端

一条命令接入 Claude Code / Codex / Cursor。新任务开始时问一句"关于 X 我们之前定过什么"。

FAQ

和直接翻 ~/.claude/projects 有什么区别？

你都可以——一次性、单一格式、单机。Vault 给你跨 harness、跨月份的统一可查询存储：会话演进的 lineage、上游变动的审计痕、全部历史之上的记忆提取。

和搬运工工具（session-migrate / txcript）冲突吗？

不冲突，是上下游：Vault 的 19 格式桥接正是驱动 session-migrate 实现的。它们管搬运，Vault 管存储、谱系、账本、审计。

免费吗？

核心 MIT 永久免费。另有闭源 Windows 托盘伴侣（自动入库、每日备份、常驻控制台）；开源核心离开它完整可用。
